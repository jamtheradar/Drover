# Drover 0.6.0

## Highlights

- **Session history browser** — a new **Session history** window (sidebar footer, or `history` in the command palette) lists every past session's Markdown transcript across all projects, newest first, rendered as a formatted document. Live search greps the whole corpus: the session list filters to matches with per-session counts, hits highlight in the open transcript with tick marks on the scrollbar, and Enter/F3/Shift+F3 navigate between them. Filter by project, or double-click a session to open the file itself.
- **Export & Find fixed at the default logging level** — Export history, the in-tab Find window, and "Open session log" previously required the raw VT trace that only exists at the Full logging level, so on default settings they silently did nothing. They now prefer the clean Markdown transcript, exported transcripts keep their Markdown formatting (no more stripped terminal dump in a code fence), and a missing log produces a clear status-bar message plus an `app.log` entry.
- **Live agents in the Agents panel** — the kanban Agents view pulses the card of each subagent currently running in the active tab, sourced from Task-tool hook events. Built-in agents with no local definition (general-purpose, Explore, plugin agents) get a synthetic card while they run; the set clears at turn end.
- **Claude 5 cost tracking** — token pricing updated for the Claude 5 family (Fable 5 / Mythos 5, Opus 4.8 including Opus's price drop to $5/$25 per MTok, Sonnet 5). Unrecognised model ids fall back to family pricing so a brand-new model shows approximately-right costs instead of zeroing the dashboard.
- **Cheat sheet refresh** — the F1 cheat sheet now tracks Claude Code v2.1.159: background tasks (`Ctrl+B`), rewind (`Esc Esc`), `/usage`, `/context`, `/goal`, fast mode, Mac Option keys, and more.

## Also

- **Gemini support** (belated note): Google's Gemini CLI shipped quietly in 0.5.0 as a third project kind alongside Claude and Codex — pick it in the New Project dialog, configure the executable path and API key in Settings.
- Session transcripts now record the project name in their header, which feeds the history browser's project filter.
- Velopack updater bumped to 1.2.0; Microsoft.Extensions.Hosting to 10.0.9.
